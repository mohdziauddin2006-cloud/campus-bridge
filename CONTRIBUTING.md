# ▓ CONTRIBUTING // CAMPUS-BRIDGE ▓

> <samp><kbd>BUILD GATE</kbd> // <b>NEOMORPHIC REGIME</b> // <kbd>PATCHES: VERIFIED OR DENIED</kbd></samp>

This is the SIH26044 academia–industry portal — a working build, not a playground.

## 01 // THE ONE LAW

```diff
- THE BUILD IS THE ONLY WITNESS. RUN `npm run build` BEFORE YOU CLAIM ANYTHING WORKS.
```

Zero `ReferenceErrors`, zero missing imports. Every icon and component is imported explicitly at the top of its file — imports don't materialize because you feel like it.

## 02 // DESIGN SYSTEM

Dark Neomorphic is enforced, not suggested: `#1b1e23` grounds, `#e2e8f0` text, `#10b981` accents; extruded cards, pressed inputs. A patch that arrives with a pastel gradient will be processed and rejected.

## 03 // STACK + STACK

`React 18` `Vite 5` `Tailwind CSS 4` `React Router 7` `Recharts` `lucide-react`
<samp><b>BACKBONE:</b> Supabase · Firebase · Google GenAI</samp>

- <kbd>npm run dev</kbd> → local dev loop
- <kbd>npm run build</kbd> → verification
- <kbd>npm run preview</kbd> → sanity check

## 04 // FILING

- **<kbd>SYS-FAULT</kbd>** — what broke, when, and the exact sequence.
- **<kbd>UPGRADE DIRECTIVE</kbd>** — what gains power for placement cells or the industries watching them.
