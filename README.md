Placement cells and the companies demanding their people currently coordinate like it's a lost shipment. Campus-Bridge is the fix: an academia–industry collaboration portal built to the SIH26044 problem statement — one live channel where demand arrives, capacity gets mapped, and the gaps are too visible to unsee.

## 01 // LOADOUT

<samp><b>NODE SIDE:</b> React 18 · Vite 5 · Tailwind CSS 4 · React Router 7 · Recharts · lucide-react</samp>
<samp><b>BACKBONE:</b> Supabase · Firebase · Google GenAI</samp>

## 02 // DIRECTIVE: DEPLOYMENT

<kbd>npm install</kbd> — then:

```bash
npm run dev      # local dev server
npm run build    # artifact check — zero ReferenceErrors, zero missing imports
npm run preview  # inspect what the build just produced
```

```diff
- BUILD. VERIFY. THEN SPEAK. THE ORDER IS NOT NEGOTIABLE.
```

<span style="color: #FF0000;"><b>The build is the acceptance test.</b></span> Run it before you claim any change works; the core does not take your word for it.

## 04 // DESIGN_SYSTEM

Dark Neomorphic, on purpose: deep `#1b1e23` surfaces, emerald `#10b981` accents, cards confessed by their shadows — extruded at rest, pressed when touched. It looks like hardware because the interface should behave like hardware.
